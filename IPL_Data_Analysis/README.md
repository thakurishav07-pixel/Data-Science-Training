# IPL Statistics Analysis

## Project Overview
This project focuses on analyzing Indian Premier League (IPL) data using Python and Pandas to extract meaningful insights about player and team performances.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Google Colab
- Jupyter Notebook

## Dataset
IPL match and ball-by-ball datasets were used for statistical analysis and data exploration.

## Analysis Performed
- Top Run Scorers
- Most Wickets Taken
- Most Runs Conceded by Bowlers
- Total Overs Bowled by Bowlers
- Player Performance Analysis
- Data Cleaning and Data Exploration

## Files Included
- IPL_Data_Analysis.ipynb
- IPL Dataset Files

## Key Insights
- Identified the highest run-scoring batsmen in IPL history.
- Analyzed bowling performances across multiple seasons.
- Calculated runs conceded and overs bowled by bowlers.
- Extracted meaningful statistics using data analysis techniques.
